# skills.ayushchugh.com

This is the site for the agent skills I use. It reads each `SKILL.md` from the `skills` folder in the repo root and renders it.

The live site is [skills.ayushchugh.com](https://skills.ayushchugh.com). How to install the skills is in the [root README](../README.md).

## Run it

From this folder:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
